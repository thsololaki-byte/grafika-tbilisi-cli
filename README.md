# Grafika Tbilisi CLI

Official command-line client for Grafika Tbilisi's public restaurant API. It reads business information and prints menu and reservation links.

```sh
npm install --global grafika-tbilisi-cli
grafika details
grafika menu --language ka
grafika reservation
```

Requires Node.js 22 or newer. Commands do not create reservations.
